Gmail Job Search

A private, owner-operated desktop connector for local Gmail archiving and job-search correspondence. This site provides application information and privacy disclosures for Google OAuth. It is not the connector, a mailbox viewer, or a public sign-up service.

Setup status: The connector is being configured for personal use. The public site contains no email messages, mailbox archives, job-application records, credentials, or account tokens.

Purpose and functionality

The workflow imports the owner's existing mailbox exports once and uses manually triggered incremental refreshes rather than repeated full exports. Working message files are stored in an owner-selected iCloud-synchronized project folder. The active index and synchronization checkpoints remain local, outside iCloud. Job-search processing is separate from complete mailbox storage. Accounts remain separate, and no messages are sent or employer applications changed.

Why Gmail permission is needed

The application requests only https://www.googleapis.com/auth/gmail.readonly. This permits reading Gmail messages, attachments, labels, account metadata, and change history needed for local archiving and refresh. Google grants this permission for the entire authorized mailbox, not only recruiting messages. Relevant-message filtering happens locally.

The application does not request permission to send email, modify messages or labels, or delete Gmail messages. Each account is authorized separately. Use is limited to the operator's own accounts, subject to any school or Workspace administrator restrictions.

Local operation and owner control

The OAuth callback runs temporarily on localhost during sign-in. Credentials and tokens are not hosted on this site. Refresh tokens are stored in the owner's local macOS Keychain. No recurring refresh or background schedule is enabled. Import and synchronization do not transfer message contents to AI. The privacy policy describes the additional copies made through the owner's iCloud account.

See the privacy policy for data access, storage, sharing, and revocation details, and the usage terms for the tool's permitted use.

Gmail Job Search's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
